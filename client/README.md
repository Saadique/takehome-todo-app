# TODO Client (React)

## Overview
Frontend for the TODO app with two columns:
- TODO
- DONE

Items move between columns when marked done.

## Tech stack
- React (Vite)
- Mantine UI

## Environment variables
Create a `.env` file in `client/`:

# Example
VITE_API_BASE=http://localhost:4001

## Install and run:
- npm install
- npm run dev

- The app runs on: http://localhost:5173/
